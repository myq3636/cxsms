# Core 第 7 批：测试用例与执行报告（DB 兜底同步执行、长短信默认 Redis 合并、过期扫描放到 Core）

> 设计见《Core第7批优化设计》。同时对前几批和通道限速做了全量回归。第 1 到 3 节是用例设计，第 4 节是执行结果。

## 1. 测试环境

与之前的报告相同：本地 Redis 7.2.5，JDK 17，真实的 Core 初始化，没有数据库。

- 新增测试套件 `Batch7IT`。
- `ConfigReloadIT` 增加了 6 个新配置项的热加载检查，并检查代码确实按热加载后的值运行。

测试方法：
- **MT 的处理**：按 `MTStreamConsumer` 的方式执行，即"开始处理 → `processSubmitFromStream` → 成功则确认消费，失败则放弃"。
- **崩溃**：第一次处理放在一个单独的线程里，执行到指定位置后线程直接结束。
- **占用时间**：`CoreMtLeaseMs` 缩短为 0.8 秒。
- **过期时间**：`CsmIntegrityCacheTimeout` 缩短为 1 秒。
- **写库失败**：本地没有数据源。带 UDH 的消息会走同步写库，用它制造写库失败。

## 2. 用例

### 2.1 DB 兜底同步执行

| ID | 场景 | 预期 | 套件：检查 | 级别 |
|---|---|---|---|---|
| B7-A1 | 路由失败（客户 8888 发往没有路由的号码） | 处理返回时，OUT_SUBMIT CDR 和失败 DR 都已经写出，然后确认消费；不经过 `DBBackupHandler` 线程池 | Batch7IT：`B7-A1a` 到 `B7-A1c` | P0 |
| B7-A2 | 处理完成、标记已写入，但确认消费失败，随后重投 | 不再写 CDR，不再回 DR | Batch7IT：`B7-A2a`、`B7-A2b` | P0 |
| B7-A2c | 失败 DR 已写出、`finish` 还没写入标记时崩溃（几毫秒的窗口） | 重投时再回一次 DR：至少一次，不会丢 | Batch7IT：`B7-A2c` | P1 |
| B7-A3 | 可重试的失败，写 RMQ 时数据库出错 | 兜底未完成，不确认消费；标记里保留 CDR，撤销 RMQ 写入；重试时重新写 RMQ，不重复写 CDR | Batch7IT：`B7-A3a` 到 `B7-A3c` | P0 |
| B7-A4 | `CoreDbFallbackInline=false` | 恢复使用线程池，失败 DR 异步送达 | Batch7IT：`B7-A4` | P1 |

### 2.2 长短信 Redis 合并

| ID | 场景 | 预期 | 套件：检查 | 级别 |
|---|---|---|---|---|
| B7-B0 | 没有配置 `CsmReassembleMode` | 使用 redis 模式 | Batch7IT | P0 |

| B7-B6 | 外发后、收尾前崩溃，最后一段被重投 | 占用期内返回 BUSY；占用期过后重新处理，不再外发（依靠去重标记里的外发记录），然后收尾 | Batch7IT：`B7-B6a` 到 `B7-B6d` | P0 |

### 4.1 性能（B7-P，单线程，完整的 MT 处理流程）

| 运行 | 3000 个长短信分段（1000 条长短信） | 3000 条普通短信 |
|---|---|---|
| 单独运行 Batch7IT | 28107 ms | 19958 ms |
| 全量回归 | 25027 ms | 20126 ms |

- 每个分段都要先走完整的入口处理（CDR、黑白名单等），与一条普通短信相同。所以长短信的总耗时与普通短信在同一个量级；每条长短信只外发一次，节省了外发的开销，但多了分段存储和收尾的开销。
- 处理过程中没有全局锁，多个 worker 线程可以并行处理。legacy 模式的对比见 X-71。

### 4.2 执行过程中的调整和发现

| 问题 | 原因 | 处理 |
|---|---|---|
| 第一版 B7-A2 中，重投时 CDR 和 DR 都重复了 | 测试模拟的崩溃点在"所有副作用都已完成、去重标记还没写入"。MT 的标记在 submitMq 上，失败 DR 在 reportMq 上，标记要等到 `finish` 时才写入 | 拆成两个用例：标记已写入只是确认消费失败（B7-A2b，不重复），以及在这几毫秒窗口内崩溃（B7-A2c，至少一次）。设计文档已注明这个窗口 |
| 第一版 B7-P1 失败 | 检查时把 B7-B5 故意留下的组也算了进去 | 改为只检查性能测试自己的组 |
| 本地日志里有 `MailSender` 空指针 | 本地没有配置告警邮件，写库失败时初始化 `MailSender` 出错 | 环境问题，不影响逻辑（B7-A3 通过） |
| 第一次试跑时 `redis-cli ping` 卡住 | 本地 Redis 已经停止，ping 一直没有返回 | `run-all.sh` 中给 ping 加了 5 秒超时 |
